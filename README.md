# Ghanigorup — Ghani Group

منصة تأجير معدات التصوير السينمائي لشركة **Ghani Group** — `ghanigroup.online`

| المجلد | المحتوى |
|---|---|
| `/` (الجذر) | تطبيق iOS و Android (Flutter) + `codemagic.yaml` للبناء والرفع الآلي على المتاجر — التفاصيل في [README.app.md](README.app.md) |
| `web/` | سكربت الموقع: PHP 8.1+ / MySQL — الموقع، REST API، لوحة التحكم، معالج التنصيب — التفاصيل في [web/README.md](web/README.md) |
| `docs/` | دليل الرفع على App Store و Google Play، ونصوص المتجر |
| `store/` | الأيقونات، Feature graphic، لقطات الشاشة |

## البدء السريع
- **الموقع:** ارفع محتويات `web/` إلى السيرفر وافتح `https://ghanigroup.online/install/`
- **التطبيق:** اربط هذا المستودع بـ Codemagic واتبع [docs/STORE_SUBMISSION.md](docs/STORE_SUBMISSION.md)
